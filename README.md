It serves as the **Frontend Demo (v1.0)** of a Full-Stack Web Application that will eventually feature a Node.js/Express REST API and a MySQL database.

### ✨ Features & Functionality (v1.0)

* **Authentication Flow:** Client-side login validation with mock credentials and sign-up input constraints.
* **Daily Task Management:** Real-time state management for creating, completing, and deleting tasks.
* **Task Status Engine:** Automatic status calculation (Pending, Completed, Expired based on due time).
* **Browser Persistence:** Uses `LocalStorage` to persist task state across sessions with a daily reset strategy.
* **Responsive Design:** Mobile-friendly drawer navigation (accessible via the notebook icon on smaller screens).
